How it works

What is N-Queens?

Place N queens on an N×N chessboard so that no two queens attack each other: no shared row, column or diagonal.

How does backtracking work?

  1. Place a queen in the current row.
  2. Check whether it is safe.
  3. If it is, move on to the next row.
  4. If no column in a row works, backtrack.
  5. Remove the previous queen.
  6. Try its next column.
